# HPFS Common V2 migration

Independent native read-only standard HPFS development candidate. Clean
volume validation, allocation bitmaps, fnode/anode B+ trees, directory
dnode traversal, case-insensitive ASCII names, ordinary file payloads,
and hosted/freestanding AMD64 carrier builds. The byte-authored fixture
is not an independent OS/2-formatted image. Active hotfix remapping,
HPFS386, EA/ACL interpretation, non-ASCII code pages, dirty media,
full ownership reconciliation, writing, formatting, defragmentation
and release remain outstanding. No unavailable capability is advertised.
